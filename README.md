## 🏗️ Things I've Built

I enjoy creating products that solve actual problems. Here are some of the projects I've been working on.

### 01. Orbit Messenger

**Real-Time Communication Platform**

A modern messaging application focused on making online conversations simple, seamless and reliable.

- Real-time one-to-one messaging.
- Media sharing and message previews.
- Online presence and typing indicators.
- Read receipts, message editing and deletion.
- Self-destructing messages.
- Built using Next.js, TypeScript and Supabase.

🔗 [Live Application](https://orbitmessenger.vercel.app)

### 02. Linkova

**Link-in-Bio SaaS Platform**

A platform that helps creators build and manage their digital presence through customizable link pages.

- Custom profile pages and themes.
- Multiple page management.
- Image cropping and customization.
- Real-time analytics.
- Authentication and database integration.
- Built using Next.js, TypeScript, Supabase and Clerk.

🔗 [Live Application](https://linkova.vercel.app)

### 03. Melova

**Music Streaming Web Application**

An immersive music listening experience with a social-style interface and personalized playback environment.

- Music streaming and playback controls.
- Automatic next-track queue.
- Full-screen backgrounds for songs.
- Admin music upload functionality.
- Built using Next.js and Supabase.

🔗 [Live Application](https://melova-music.vercel.app)
